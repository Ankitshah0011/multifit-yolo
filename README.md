# MultiFit Pradhikaran - Free Trial Landing Page

A landing page for MultiFit Pradhikaran gym that uses **YOLOv8 object detection** (via TensorFlow.js) to verify users by scanning the MultiFit logo. Includes geolocation-based eligibility check (within 3km), an enrollment form, and Google Sheets integration for lead capture.

**Tech:** HTML, CSS, JavaScript, Three.js, TensorFlow.js, YOLOv8.
